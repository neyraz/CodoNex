CodoNex

Codon usage explorer for DNA & RNA — from a single gene to a whole genome

Save your work as one file and open it later to continue.

Paste sequences or load FASTA files (plain, .gz or NCBI .zip, several at once) — get codon counts, amino-acid composition, GC content, ENC, six-frame ORF finding, codon usage (RSCU) and a filterable gene table with Excel export.

Paste sequences into the box, or drag files onto the input card — several at once. CodoNex reads FASTA (.fasta .fa .fna .ffn .txt), gzip (.gz) and zip (.zip) files as they are, without unpacking.

1Whole genome — every gene (NCBI)
  1. Find the genome assembly at NCBI (e.g. GCF_000012685.1, M. xanthus DK 1622).
  2. Open the assembly's FTP folder and download …_cds_from_genomic.fna.gz.
  3. Drop the .gz file here. Gene names, locus tags and products are read from the headers.

Or download the genome package from the assembly page with the coding-sequence (CDS) FASTA included, and drop the .zip — CodoNex picks the CDS file inside.

Quickest: type the accession (e.g. GCF_000012685.1) into the NCBI box of the input card and click Download from NCBI. CodoNex fetches the CDS file for you (needs internet).

2One or a few genes (NCBI Nucleotide)
  1. Open the GenBank / RefSeq record.
  2. Send to → Coding Sequences → Format FASTA Nucleotide → Create File.
  3. Drop the downloaded file here.
3A list of genes or accessions
  • Locus tags: load the whole genome (route 1), paste your list into the Gene explorer search and set Match to is exactly; then download the hits as Excel or FASTA.
  • Accession numbers: put one per line in a text file, upload it to NCBI Batch Entrez (database Nucleotide), then Send to → Coding Sequences → Format FASTA Nucleotide → Create File (File → FASTA would give the whole records instead of their genes).
4KEGG or Ensembl
  • KEGG: open the gene's entry (e.g. mxa:MXAN_0001); the NT seq row holds its DNA — open it as FASTA and paste it into the box.
  • Ensembl: bacterial genomes moved from Ensembl Bacteria to the new ensembl.org in 2026. Download your genome's cDNA or CDS FASTA (.fa.gz) and drop it here; Ensembl Bacteria's last release (63) stays on the Ensembl Genomes FTP site.
5Starting from UniProt

UniProt stores proteins, and protein FASTA is skipped here because codons need DNA. Use the entry's gene name, locus tag or its EMBL / GenBank cross-reference to get the coding DNA from NCBI (route 2 or 3).

6Your own sequences
  • Prokka annotation: load the .ffn file (all predicted genes; it also holds rRNA and tRNA genes — set Flags to No flags to hide most of them).
  • Plasmids, Sanger reads, SnapGene / Benchling: export or copy as FASTA, or paste the plain sequence.
  • Several sequences in the box: give each its own >name line — lines without a header are joined into one sequence.
7A saved CodoNex session

Save session (top right, or Ctrl+S) puts your sequences and every setting, filter, column choice and view into one .codonex file. Later, click Open session… or drop the file onto this page to carry on where you left off.

Fetches the coding sequences (CDS) of the genome from NCBI Datasets — needs an internet connection. Chromosomes and plasmids are named in the Replicon column.

Patterns are read left → right. N (or X, .) is a wildcard: ANN = every codon starting with A, AUN = A-U-anything, GC = every codon starting with GC. IUPAC codes are supported (R Y S W K M B D H V). A single letter counts all codons starting with that base. T and U are treated as equivalent. IUPAC ambiguity letters in the sequence are treated as N, so the reading frame is never shifted. "Longest ORF" scans all six frames for the longest start … stop stretch.

Pasted text and loaded files are analysed together; remove a file with its ×. Protein FASTA (e.g. from UniProt) is recognised and skipped, because codon analysis needs DNA or RNA.

    Gene explorer

    Filters

    Numeric filters: pick a value (length, GC, ENC, amino-acid %, codon %, codon type such as ANN %, RSCU …) and give a min and/or a max. Amino-acid % is of translated residues; codon % and codon-type % are of all codons in the gene. Protein motifs: x = any residue, [ST] = S or T, {P} = anything but P, x(2) or x(2,4) = repeats. DNA motifs accept IUPAC letters (N R Y S W K M B D H V).

    Click a column header to sort (click again to reverse); click a row to open that gene in the codon usage card below. Downloads include every sequence that passes the filters, not just this page. GC1 / GC2 / GC3 = GC at codon position 1, 2 or 3; GC3s = synonymous third positions only (single-codon amino acids — Met, and Trp in the standard code — and stops excluded). ENC = effective number of codons: 20 = one codon per amino acid (strongest bias), 61 = no bias (62 with genetic code 4); blank for very short genes.

    Rows = 1st base, columns = 2nd base, and the four codons in each box differ in the 3rd base, as in the standard codon table. The coloured line beside each amino acid marks its side-chain class; shading shows the value selected above (hover a codon for all values).

    Per 1000 = codon count ÷ all codons × 1000. Fraction = share of the codon among the codons of its amino acid. RSCU = observed ÷ expected if all synonymous codons were used equally (1 = no preference, > 1 preferred, < 1 avoided).

    Each codon chip shows: codon, count and RSCU. Percentages are of translated residues (stop codons, and X from codons containing N, excluded). Side-chain classes follow Lehninger's grouping; chemical, hydropathy and volume classes follow IMGT.     Codon adaptation index (CAI)

    CAI compares the codons of each gene with those of a reference set of highly expressed genes. It runs from 0 to 1: genes with a high CAI use the codons the cell prefers, and are usually strongly expressed. Every gene gets a CAI column in the gene explorer, so you can sort or filter by it.

    CAI of every gene

    Save picture

    Codon weights of the reference genes w = how often a codon is used in the reference genes, relative to the most-used codon of the same amino acid (w = 1). Codons with w = 1 are the “preferred” ones.

    How it is calculated (Sharp & Li 1987, Nucleic Acids Res 15:1281–1295): the codon counts of the reference genes are pooled; w of a codon = its count ÷ the count of the most-used synonymous codon; a codon never seen in the reference counts as 0.5. CAI of a gene = the geometric mean of w over all its codons. Amino acids with a single codon (Met, and Trp in the standard code) and stop codons are left out. Ribosomal-protein genes are recognised from gene names (rpl, rps, rpm) and products such as “50S ribosomal protein L2”; pseudogenes, partial genes and genes with internal stops are not used as reference. With several genome files, each file uses its own reference genes unless you pick one genome — that lets you ask, for example, how well M. xanthus genes fit E. coli.

    Codon optimizer re-codes a protein or a gene with the codons of the reference genes above

    Each amino acid gets a codon from the reference genes’ weights (w). “Most-used codon” gives the highest CAI; “Mix as in reference” spreads the allowed codons in the same proportions as the reference genes, evenly along the sequence (a more natural sequence with a slightly lower CAI). Codons below the cut-off are never used unless that is the only way to remove a site you asked to avoid. Sites are checked on both strands; enzyme names are looked up in a built-in list of common cloning enzymes (recognition sequences as listed by NEB). The result is always checked to translate back into exactly your protein.

    Compare groups genes passing the filters against all other genes

    Do the genes you picked with the gene-explorer filters differ from the rest? For example plasmid genes against chromosome genes, your peptidoglycan genes against the whole genome, or genes with a high CAI against the others. Pick a measure, or test every measure at once. The test (Mann–Whitney U) does not assume that the values follow a bell curve.

    Mann–Whitney U test, two-sided (Mann & Whitney 1947, Ann Math Stat 18:50–60): exact for groups of up to 25 genes without tied values, otherwise the normal approximation with corrections for ties and continuity. Effect size = Cliff’s delta (Cliff 1993, Psychol Bull 114:494–509), from −1 to +1: the chance that a gene of group A has the higher value, minus the chance that it has the lower one. |delta| below 0.147 is called negligible, below 0.33 small, below 0.474 medium, otherwise large (Romano et al. 2006, Annual Meeting of the Florida Association of Institutional Research). “Test every measure” corrects for testing many measures at once with the Benjamini–Hochberg false-discovery rate (Benjamini & Hochberg 1995, J R Stat Soc B 57:289–300). With thousands of genes even tiny differences give small p-values, so look at the effect size too.

    Gene inventory peptidoglycan synthesis & remodelling

    Finds the genes of a pathway from their annotation (gene name and product) and checks typical protein motifs. Load two or more genome files (one per strain) to compare them side by side. Click a gene to open it; hover for details.

    Edit the gene list (rules)

    One line per row: Name | gene symbols | product words | words that exclude | motifs. A line starting with # starts a group. Product words are matched in the product name as whole words (case-insensitive; separate several with ;). Gene symbols must match exactly, or end with * (e.g. murA*). Motifs: PBP = SxxK … SxN … K(T/S)G in this order, GT51 = E-D-x-x-F-x-x-(H/N)-x-(G/A), or a protein pattern such as S-x-x-K. +PBP = must be present, -GT51 = must be absent, plain = only shown. A row may have no gene symbols and no product words if it requires a motif (My PBPs | | | | +PBP): every gene with that motif then goes into it. Each gene goes to the first row it matches.

    Groups follow KEGG BRITE ko01011 “Peptidoglycan biosynthesis and degradation proteins” and KEGG pathway map00550 “Peptidoglycan biosynthesis”. Added to KEGG's lists: GlmS, GlmM and GlmU, PgpB, Amj, PBP and amidase activators, MepK, NlpC and YafL, VirB1, more recycling enzymes (AmpG, NagZ, AnmK, MurQ, Mpl, MpaA), cell shape and division proteins, Pal and other PG-binding proteins, and β-lactamases; KEGG's sortases, DgkA, MurD2 and MurL are not included. Words were checked against the NCBI RefSeq annotations of E. coli K-12 MG1655, M. xanthus DK 1622 and A. fabrum C58. PBP motifs searched for: SxxK, SxN and K(T/S)G, in this order (for PBP structure and function see the review by Sauvage et al. 2008, FEMS Microbiol Rev 32:234–258); KSG is accepted as well as KTG, and the spacing limits (SxN 20–300 aa after SxxK, K(T/S)G 40–300 aa after SxN) were set to fit the PBPs of these three genomes. The GT51 motif (glycosyltransferase module of class A PBPs and MtgA) follows Terrak & Nguyen-Distèche (2006) J Bacteriol 188:2528–2532. ◆ = placed by its motifs rather than its name. Annotation-based: always check unexpected hits and gaps.

    Self-check

    Runs 50 small calculations whose answers are known — codon counting, translation, GC, RSCU, ENC, CAI, the codon optimizer, motif search, the gene inventory, the statistics, reading .gz files and writing Excel files.
